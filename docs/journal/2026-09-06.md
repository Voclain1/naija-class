## The finding of the day

A real teacher's manual pass found that the not-grounded message rendered as
ordinary muted text. Investigating it surfaced something worse than the styling
gap: **D42's two actions were structurally unreachable on the `no-match`
branch**, which is the branch a teacher hits when the floor rejects everything.
The actions only rendered when retrieval returned junk AND the model rejected
it. Nothing automated caught this, because both branches were individually
correct — the gap was in which branch real usage reaches.

Also found while fixing it: `QUERY_SET_NOTE` was missing a `+` between two
string literals. Not a syntax error (ASI ends the statement), so it passed
typecheck, lint and CI while silently truncating the provenance banner and
dropping the "numbers are provisional" caveat from every run. Mine, from #266.
