# 2026-09-03 - Onboarding guide urgent factual correction

## Scope

Corrected only two active inaccuracies in `docs/onboarding-guide.md` before
a planned demo recording. This was not a broader documentation refresh.

## Changes

- Paystack copy now states that payments are live once a school is connected
  and that a fulfilled assisted-setup request connects automatically; the
  retired owner code-pasting flow was removed.
- The Subjects section now identifies the three seeded subjects as a small
  starter set, not a promised WAEC/NECO catalogue, and records that broader
  national catalogue work was investigated and deliberately deferred.

## Audit finding retained for the next scoped guide update

The core fresh-school sequence is not camera-ready in the existing guide:
Step 5 is still described as **You're all set** / **Go to dashboard**, while
the current onboarding step is the required academic-calendar form
**Set up your school year** with **Finish setup**. A demo must complete that
calendar step before adding and enrolling students. This was reported, not
rewritten, because the request limited this edit to the two urgent factual
corrections.
