Lessons from #388's CI, both written into `docs/deferred.md`:
- An unordered `findMany` feeding an asserted audit row is flaky. Sort it.
- `history.replaceState` is not a safe way to write a URL param in Next 15.
  With Next's state it never reaches `useSearchParams`; without it, Next's
  sync cancels an in-flight navigation just as `router.replace` does. A race
  test that checks only the URL missed the first failure; assert the page
  renders.
