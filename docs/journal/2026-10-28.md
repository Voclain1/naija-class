  incident. The disabled gate must run before any loader or parameter error.

  restriction and links to the grid or existing pupils' Enrollments tabs.
- Require an explicit class/later answer where classes are available. The
  single-student picker's no-calendar/no-classes fallback remains available.
- Fix placement after any saved row, including if the saved row is removed
  from the grid, so a partial retry cannot change its destination class.
- Update the onboarding guide and module spec in this build.
